# FST-Chemistry

Domain supplements applying Functional Stability Theory to chemical systems.

**Status:** Planned as a domain supplement. The existing public FST-II chemistry
line is represented by reproducibility artefacts in
[`../applications/fst-ii-chemical/`](../applications/fst-ii-chemical/).

The separate `../applications/fst-ii-chemistry/` path is historical/conceptual
integrated v2.0 source material, not a released FST-II package and not a public
release link. Its circularity warning and untested P3 experiment remain open.
