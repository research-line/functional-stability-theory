# Selberg — NE-B Failure as Hilbert–Pólya Detection

**NE-B Failure as Hilbert–Pólya Detection: Universality of the v2.0 Weil Quadratic Form on the Selberg Zeta Function**

The Selberg paper is the *positive method-validation* of the v2.0 framework: it tests the v2.0 method (developed for the Riemann Hypothesis) on the Selberg zeta function of a compact hyperbolic surface Γ\H — a classically tractable case via the Selberg trace formula — and shows that the framework correctly diagnoses the SGE-YES regime.

## Main result (in one sentence)

**NE-B fails for Selberg** — the Laplace–Beltrami operator Δ is a universal commuting operator for all geodesic-shift transfer operators by isometry invariance. Hence:

- where a classical commuting operator exists (Selberg, via Casimir): v2.0 is redundant but valid — Hilbert–Pólya works as a **special case of v2.0**;
- where it does not (Riemann, by NE-B): v2.0 is the only available route.

The **Weil quadratic form** is the universal structure; the operator is *optional*.
