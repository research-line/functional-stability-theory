Each addresses a different audience while sharing the same underlying framework.

Atlas and Selberg are the explicit method-validation pair: Atlas is the
negative leading-order Galerkin test, while Selberg is the positive
operator-based validation. Their local candidate states do not change the
archived Record DOI values above.

“Concept DOI” denotes the always-latest DOI anchor. A Record DOI is listed only
where the corresponding master README states it; a missing local record entry
is deliberately marked as not verified rather than guessed.

## Entry Points

- **Coming from number theory?** Start with `zookeeper/` (CCM route, three-lemma proof mechanism).
- **Looking for the classification?** Start with `zeta-zoo/` (SGE dichotomy, six zoo instances, Boundary Theorem).
- **Coming from physics?** Start with `spectrum-duality/` (FST axiom package, physical interpretation).
- **Looking for domain-specific results?** See `../domain-proofs/`.
