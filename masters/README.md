# FST Masters — Foundation Papers

The master-level papers provide the theoretical foundations of FST.
Each addresses a different audience while sharing the same underlying framework.

| Master | Title | Audience | Status |
|--------|-------|----------|--------|
| **spectrum-duality/** | FST Spectrum Duality (Three-Lemma Endgame) | Number theory, spectral theory | Draft v0.8 |
| **math-master/** | The Zeta Zoo (Classification) | Pure mathematics | Draft v1.1 (planned) |
| **physics-master/** | RFEP (Physical Instantiation) | Mathematical physics | Published v1.7 |

## Entry Points

- **Coming from mathematics?** Start with `spectrum-duality/` (proof mechanism)
  or the classification in `math-master/` (planned).
- **Coming from physics?** Start with `physics-master/` (= `../framework/`, to be migrated).
- **Looking for domain-specific results?** See `../domain-proofs/` (physics) or
  `../mathematics/` (planned: Selberg, Dirichlet, etc.).
