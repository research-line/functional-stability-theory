# FST Masters — Foundation Papers

The master-level papers provide the theoretical foundations of FST.
Each addresses a different audience while sharing the same underlying framework.

| Master | Title | Audience | Status | DOI |
|--------|-------|----------|--------|-----|
| **zookeeper/** | The Spectral Zookeeper (RH via Microcluster Closure) | Number theory, spectral theory | PP v1.0 | 10.5281/zenodo.19673127 |
| **zeta-zoo/** | The Zeta Zoo (HP-BL Classification, SGE Taxonomy) | Pure mathematics | PP v1.1 | 10.5281/zenodo.19673227 |
| **spectrum-duality/** | FST Spectrum Duality / RFEP (Physical Instantiation) | Mathematical physics | PP v1.7 | 10.5281/zenodo.19162705 |

## Entry Points

- **Coming from number theory?** Start with `zookeeper/` (CCM route, three-lemma proof mechanism).
- **Looking for the classification?** Start with `zeta-zoo/` (SGE dichotomy, six zoo instances, Boundary Theorem).
- **Coming from physics?** Start with `spectrum-duality/` (FST axiom package, physical interpretation).
- **Looking for domain-specific results?** See `../domain-proofs/`.
