# FST-Biology

Domain supplements applying Functional Stability Theory to biological systems.

**Status:** In development. The public FST-III biological application lives in
[`../applications/fst-iii-biological/`](../applications/fst-iii-biological/).
The standalone chaperone game-theory companion **FST-Nash** is separate from this
repository and is maintained in
[`research-line/fst-nash`](https://github.com/research-line/fst-nash).
