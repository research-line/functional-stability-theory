## Honest status (v1.0 / v1.1)

These are the initial published versions. The Hub paper documents the architecture; the four application papers carry the audit-level readiness scores per the FST programme's status overview:

- **Hub:** programmatic survey, "honest survey" stage, structural and reductive contribution.
- **FST-I:** ~8.5/10 readiness, referee verdict *"publication recommended provided speculative scope made more explicit"*.
- **FST-II:** ~8.5/10 readiness, referee verdict *"publish after minor revision"*.
- **FST-III:** ~7.5/10 readiness, referee verdict *"publish after moderate revision"*.
- **FST-DE:** PP-FULL stage, framework + Convexity-Screening No-Go Theorem.

Future versions (v1.1+) will close the remaining audit-level items in each paper.
